This is my final B457 project. This is an attempt to create a cat emotion detector using deep learning and computer vision techniques. The data I used to train my models are in the Data folder, the result images for the training and detection is stored in the result_images folder, and the quick testing images are stored in the small_test_images. The models are saved as h5 files. To run this detection simply add a jpg file to this project and input the file path at the end of final_detect.py and run final_detect.py. This should output the image with the classification and the position of the tail.
